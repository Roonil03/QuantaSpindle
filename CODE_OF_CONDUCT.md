# Code of conduct

Treat other contributors with respect in issues, pull requests, and reviews. Explain disagreements using the code, evidence, or stated requirements. Accept corrections and give people room to ask questions.

Do not harass, threaten, insult, discriminate against, or publish private information about another person. Do not continue unwanted contact.

Maintainers may remove harmful content, close a discussion, or restrict participation. They should explain the rule involved when doing so does not expose private information.

No private conduct-reporting contact has been verified for this project. For a concern that can be shared safely, use a repository issue and ask a maintainer to arrange a private route. Do not include personal details or sensitive allegations in a public issue. This document does not promise a response time.
