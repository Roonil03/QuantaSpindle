# Reporting a security problem

Do not post an unpatched vulnerability, exploit, credential, or private market data in an issue.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Roonil03/QuantaSpindle/security/advisories/new). This route was enabled and verified on 2026-11-15. Do not assume a public issue or pull request is private.

Include the affected commit or version, toolchain and backend, a small synthetic reproduction, and the possible effect. Keep private data out of the reproduction.

No supported-version or response-time policy has been adopted. The CUDA runner is native code and should only be executed from a trusted local build. Numerical model limitations are documented separately from security defects.
