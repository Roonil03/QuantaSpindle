# Reporting a security problem

Do not post an unpatched vulnerability, exploit, credential, or private market data in an issue.

A private security reporting route has not yet been verified for this repository. Before public release, the owner must enable GitHub private vulnerability reporting or publish a verified security contact here. Until then, contact a maintainer through a route you already know and ask for a private channel before sharing details. Do not assume a public issue or pull request is private.

Include the affected commit or version, toolchain and backend, a small synthetic reproduction, and the possible effect. Keep private data out of the reproduction.

No supported-version or response-time policy has been adopted. The project is preparing its first release. The CUDA runner is native code and should only be executed from a trusted local build. Numerical model limitations are documented separately from security defects.
